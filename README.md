# CREATUNITY — Fashion Bureau

Editorial fashion community website based on `REVISION 02 DESKTOP.pdf`.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Implemented

- Responsive editorial homepage with extracted original imagery
- Shared navigation and footer
- Creator index with working role, city, and text filters
- Individual creator dossier routes
- Work archive and work detail routes
- Search with client-side filtering
- Create-project form with preview and session-only draft indication
- Initial editorial entry pages for Magazine, Events, Education and Account sections

## Status / limitations

This is **phase 1**, not the finished 30-screen website. Magazine, event detail, education, account and messaging are currently entry pages, not complete workflows. No backend, authentication, real messaging, uploads or payments are connected. Creator and project records are mock examples from the reference PDF. Assets extracted from the provided design reference are in `public/images/` and may remain subject to original third-party licensing.

The PDF is a single flattened sheet, so typography and spacing are approximate interpretations, not original Figma design tokens.
